앱으로 설치하기

홈 화면이나 브라우저에 두고 바로 열어 쓰세요. 설치하면 인터넷 없이도 QR 코드를 만들 수 있어요.

설치하기

쓰는 기기를 고르면 설치 방법을 알려 드려요.

이 미리보기 페이지는 설치할 수 없어요. 설치형 파일을 웹에 올린 주소에서 열면 아래 방법대로 설치돼요.

지금 설치된 앱으로 열려 있어요. 따로 설치할 필요가 없어요.

이 브라우저에서 바로 설치할 수 있어요.

Chrome에서 설치

  1. Chrome으로 이 사이트를 열어요.
  2. 오른쪽 위 메뉴를 눌러요.
  3. 앱 설치 또는 홈 화면에 추가를 눌러요.
  4. 설치를 누르면 홈 화면과 앱 목록에 ‘QR 메이커’가 생겨요.

삼성 인터넷: 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

설치하면 다른 앱의 공유 메뉴에서 링크를 QR 메이커로 바로 보낼 수 있어요.

Safari에서 홈 화면에 추가

  1. Safari로 이 사이트를 열어요.
  2. 아래쪽(또는 주소창 옆)의 공유 버튼 을 눌러요.
  3. 목록을 내려 홈 화면에 추가를 눌러요.
  4. 웹 앱으로 열기가 보이면 켜 둔 채로 추가를 눌러요.

iOS 16.4 이상에서는 Chrome 같은 다른 브라우저의 공유 메뉴에서도 추가할 수 있어요.

iPad도 방법이 같아요. 공유 버튼은 주소창 오른쪽에 있어요.

이 브라우저에서 바로 설치할 수 있어요.

Chrome · Edge · 웨일에서 설치

  1. Chrome, Edge, 네이버 웨일 중 하나로 이 사이트를 열어요.
  2. 주소창 오른쪽의 설치 아이콘 을 눌러요.
  3. 아이콘이 안 보이면 메뉴 → 전송, 저장, 공유 → 페이지를 앱으로 설치를 골라요. (Edge: ⋯ → 앱 → 이 사이트를 앱으로 설치)
  4. 설치를 누르면 시작 메뉴·Dock에서 앱처럼 열 수 있어요.

Mac Safari 17 이상: 메뉴 막대의 파일 → Dock에 추가

확장 프로그램 직접 설치

  1. 확장 프로그램 파일을 받아요.
    qr-maker-extension.zip 받기
  2. 받은 파일의 압축을 풀어 둬요. 폴더는 지우지 말고 그대로 두세요.
  3. 주소창에 chrome://extensions를 입력해요. (Edge: edge://extensions, 웨일: whale://extensions)
  4. 오른쪽 위 개발자 모드를 켜요.
  5. 압축해제된 확장 프로그램을 로드합니다를 누르고 압축을 푼 폴더를 골라요.
  6. 주소창 옆 퍼즐 아이콘 에서 QR 메이커를 고정해 두면 편해요.

확장 아이콘을 누르면 지금 보고 있는 페이지 주소로 QR 코드가 바로 만들어져요.
